Primeiro acesso

Crie a senha do administrador do FISCALE.

Bem-vindo! Este é o primeiro acesso. Crie a senha do usuário admin — é com ele que você cadastra os demais usuários.
Use pelo menos 8 caracteres. Para maior segurança, recomendamos uma frase com 12 caracteres ou mais. Guarde bem: sem ela não há acesso ao sistema.

O Sistema Web FISCALE ainda não tem usuários. Por segurança, a senha do admin só pode ser criada no próprio servidor do escritório. Faça isso lá e depois acesse o FISCALE pelo navegador.
